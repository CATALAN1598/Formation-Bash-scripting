Les arguments

Cette page présente l’utilisation des arguments d’un script

Les arguments

1- Manipulé les arguments

Les scripts peuvent intéragir avec des arguments lors de l’exécution.


#!/bin/bash
#

echo "Le nom argument du script est:                    $0"
echo "Le premier argument du script est:                $1"
echo "Le second argument du script est:                 $2"
echo "Le troisième argument du scirpt est:              $3"
echo "Le nombre d'argument du script est:               $#"
echo "L'ensemble des arguments du script sont:          $@"

Exemple: arguments/argument_1.sh

Variable Description Exemple (script.sh arg1 arg2)
$0 Nom du script ./script.sh
$1 Premier argument arg1
$# Nombre d’arguments 2
$@ Tous les arguments arg1 arg2
$* Tous les arguments en une chaîne arg1 arg2
shift Supprime le premier argument Après shift, $1 devient arg2

2- Intéragir avec les arguments

Il est possible d’utilisé les arguments du script comme n’importe quelle variable. 



#!/bin/bash
#

if [ "$1" == "-h" ]
then
        echo -e "Usage $0: Ce script attent 3 arguments\nLe premier est ignoré sauf si il vaut -h\nLe deuxième argument doit être un pays et le troisième une ville de ce pays"
fi

echo -e  "\n#\n------------------------\n#\n"
echo "Le nom du script est:             $0"
echo "Le premier argument est   $1"
echo "Le deuxième argument est  $2"
echo "Le troisieme argument est         $3"

shift
echo -e  "\n#\n------------------------\n#\n"
echo "Le premier argument est   $1"
echo "Le deuxième argument est  $2"
echo "Le troisieme argument est $3"


pays="$1"
ville="$2"

echo -e  "\n#\n------------------------\n#\n"
echo -e "J'habite à $ville qui se trouve dans le pays $pays"

Exemple: arguments/argument_2.sh

Bonne Pratique

Il est fortement conseiller de charger des variables avec un nom précis correspondant au contenu, avec les variables d’argument du script.

ex: pays="$1" lorsque le premier argument doit étre le nom d’un pays.

Cela facilie grandement la lecture du script (rappel un script DOIT être lisible) et évite les erreurs ainsi que les inversions avec les arguments d’une fonction qui se nomme de la même manière (à voir plus tard)

Une fois les arguments du scripts chargés dans les variables approprié, elle s’utilise exactement de la même manière que n’import quelle variable.

3- Aides utilisateurs

Si vous souhaitez vous assurer que l’utilisateur entre bien un argument au script vous pouvez l’aiguiller.

Vous pouvez également vérifier les arguments et réagir en fonction de leur contenu.


#!/bin/bash
#

ville=${1:?Entrez votre ville}
code_postale=${2:?Entrez le code postal de votre ville}

if [ $# -ne 2 ]
then
        echo "Le script attend 2 arguments"
        exit 1
fi

if [[ "$code_postale" =~ ^[0-9]{5}$ ]]
then
        echo "Vous habitez à $ville et votre code postale est $code_postale"
else
        echo "votre code postale ne correspond pas à une ville en France"
fi

Exemple: arguments/argument_3.sh
