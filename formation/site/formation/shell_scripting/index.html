Shell Scripting

Cette formation présente le Shell Scripting.

Introduction

Formation est destinée à un publique débutant/confirmé.

Les supports de formation

  • Il est joint à cette formation tout les scripts utilisés pour les demonstrations. Download Scripts

  • A chaque utilisation d’un script de démonstration, il est indiqué sous le code quel script est utilisé.

  • Les scripts sont écrit en BASH et ont tous été testés, ils sont tous fonctionnels.

  • Certain script présente des erreurs, elles sont voulus pour présenter de mauvaise utilisation de commande ou de variable.
