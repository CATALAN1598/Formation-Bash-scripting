Les variables

Ce chapitre présente la manipulation des variables dans des scripts shell

Les variables

Comme dans tous langage de programmation l’utilisation de variable permet de stocker des informations en mémoire afin de les appeler plus tard dans le programme.

Une variable est créée dès qu’on lui associe une valeur sinon la variable est NULL.

Elle peut être appelée tant qu’elle existe et quand elle est nécessaire.

N’oublions pas qu’un script est un enchaînement d’instructions donc on ne peut pas appeler une variable qui n’a pas encore été créée.

Une variable peut prendre plusieurs valeurs au cour de l’exécution du script, on dis qu’une variable vit.

  • Une fois une variable créée, elle peut être vidé et être toujours active avec une valeur VIDE.

  • Une fois une variable créée, elle peut être supprimer, elle ne sera donc plus active et aura pour valeur NULL.

VIDE est une valeur !!!

NULL n'est pas une valeur !!!

Type des variables

Pour ceux qui son familier avec un autre langage de programmation il n’est pas necéssaire de donner un type à une variable (int, float, bool, ect) néanmoins pour des besoins précis il est possible de le faire (très peu utilisé).

1- Déclaration d’une variable

Une variable se déclare avec une forme clé/valeur. Elle peut néanmoins posséder des paramètres supplémentaires.

Syntaxe d’une déclaration:

nom_de_la_variable=valeur_de_la_variable



#!/bin/bash

var=toto 	# la variable à pour valeur la chaîne de caractère « toto »
echo $var 	# Affiche la valeur de la variable $var : toto

Exemple: variables/variable_1.sh


# !/bin/bash
echo $var   # Affiche la valeur de $var qui n'a pas été initialisée

var=toto 	# La variable prend pour valeur la chaîne de caractère « toto »

echo $var	# Affiche la valeur de la variable $var : toto

var=tata	# Ecrase la variable $var avec la valeur la chaîne de caractère « tata »

echo $var	# Affiche la valeur de la variable $var : tata

unset $var	# Supprime la variable $var

echo $var	# Affiche le contenu de la variable $var
		    # la variable n'existe plus ça valeur est NULL
		    # Une variable doit avoir une valeur pour exister (VIDE est une valeur)
La variable vit !

Exemple: variables/variable_2.sh

Il est possible de déclarer une variable en « readonly » qui, comme son nom l’indique ne peut qu’être lus et ne peut pas être modifiée.


#!/bin/bash
readonly var=toto       # Déclaration d'une variable en readonly avec pour valeur toto
#readonly var           # déclaration d’une variable en readonly avec pour nom var
                        # La variable à pour valeur : NULL

echo $var               # Affiche le contenu de la variable $var
                        # ERREUR : la variable n’existe pas car elle n’a pas encore eu de contenu

var=tata                # ERREUR : la variable est en readonly

Exemple: variables/variable_3.sh

2- Appel d’une variable

Il est existe plusieurs moyens d’appler une variable:


#! /bin/bash


var=AZERTY

echo "ma variable est:" $var                        # Appel de la variable simple
echo
echo "ma variable est:" "$var"                      # Appel de la variable entre guimet
echo    
echo "ma variable est:" ${var}                      # Appel de la variable en inclusion 
echo
echo -e  "\n#\n------------------------\n#\n"

words="toto tata titi"                              # Déclaration d'une variable contenant une liste de mots

for word in $words;                                 # Boucle qui affiche chaque ocurence de la variable
do
        echo $word                                  # Affiche les occurences
done

echo
for word in "$words";                               # Boucle qui affiche la variable entre guimet
do
        echo $word                                  # Affiche la variable
done

echo -e  "\n#\n------------------------\n#\n"

list="\*.sh"                                        # Varaible qui défini toute les fichiers en extension .sh
echo
ls $list                                            # Liste la variable (ls \*.sh)
echo
ls "$list"                                          # Liste le fichier '\*.sh'
echo
ls ${list}                                          # Liste les fichiers de manière inclusive

3- Les variable inuput

Il est possible de demander à l’exécuteur d’entrer de la valeur avec son clavier pour chargé une variable


#!/bin/bash
#

read -p "Entrez votre nom d'utilisateur: " utilisateur  # Lis l'entré de l'exécuteur pour son nom d'utilisateur
read -p "Entrez votre mot de passe: " -s password       # Lis l'entré de l'exécuteur pour son mot de passe sans l'affiché (un peu d'intimité)
echo -e "\n"
echo "utilisateur: $utilisateur"
echo "password: $password"

hash_pass=$(cksum <<< $password | cut -d " " -f1)                               # hash le mot de passe dans la variable $hash_pass

if [[ $utilisateur == "admin" && $hash_pass == "2092279974" ]]                  # Vérifie si l'utilisateur et le mot de passe hashé sont les bons.
then
        echo "Vous avez trouver le message secret: le BASH c'est PUISSANT"      # Si oui affiche le message caché
else
        echo "Fais un effort le bon MDP va pas s'écrire tout seul !!!"          # Si non motive le chercheur
fi

Vous permettez à l’utilisateur d’intéragir avec le script il faut penser à le blindé pour évité l’injection de commande dans les variables associées au input de l’exécuteur du script

4- Les variables par defauts

Plustôt nous avons vu qu’une variable peut être :

  • Vide
  • Null

Il est possible d’associer une valeur à une variable si elle est vide ou null.


#!/bin/bash
#

var=toto

echo "La variable vaut: " $var
echo
unset var

echo "[unset] La variable var est désormais NULL"
echo

var2=${var-default variable}    # Si variable null utilise la valeur defaut

echo "[var2=\${var-default variable}] La variable vaut: " $var2 # Affiche var si pleine ou affiche defaut si var vide
echo

var=tata
echo "[var=tata] La variable var vaut $var"
echo

var2=${var-default variable}    # Si variable vide utilise la valeur defaut

echo "[var2=\${var-default variable}] La variable vaut: " $var2 # Affiche var si pleine ou affiche defaut si var vide
echo

var=""
echo "[var=""] La variable var vaut VIDE "
echo

var2=${var-default variable}    # Si variable vide utilise la valeur defaut

echo "[var2=\${var-default variable}] La variable vaut: " $var2 # Affiche var si pleine ou affiche defaut si var vide


echo -e  "\n#\n------------------------\n#\n"

declare var3                    # Déclare une variable NULL
echo "[declare var3]La variable n'a pas de valeur elle est NULL"
echo

var4=${var3:-default variable}  # Si variable est vide ou null var4 vaut default variable

echo "[var4=\${var3:-default variable}] La variable vaut: " $var4 # Affiche var si pleine ou affiche defaut si var vide
echo

var3=titi

echo "[var3=titi] La variable var vaut $var3"
echo

var4=${var3:-default variable}
echo "[var4=\${var3:-default variable}] La variable vaut: " $var4 # Affiche var si pleine ou affiche defaut si var vide
echo

var3=""

echo "[var3=""] La variable var est désormais VIDE"
echo

var4=${var3:-default variable}
echo "[var4=\${var3:-default variable}] La variable vaut: " $var4 # Affiche var si pleine ou affiche defaut si var vide

Exemple: variables/variable_5.sh

5- Les variables d’environnement

Maintenant que nous avons vu comment manipuler les variables, nous allons voir les variables d’environnement.

Grace à la commande env vous pouvez voir les variables de votre environnement.

Exemple de variable d’environnement importante. 


HOSTNAME=nom_de_la_machine
SHELL=/bin/bash
PWD=Endroit_du_filesystem_ou_l_on_se_trouve
LOGNAME=Utilisateur_logué
HOME=/home/user
PATH=chemin_systeme_d_acces_aux_bianires
ECT...

Ces variables sont celle de l’environnement dans lequel le script est exécuté. Elles peuvent être appelées dans le script sans avoir à les définir dans le script.


#!/bin/bash
#
echo "je suis connecté en tant que $LOGNAME et j'habite à $HOME dans $HOSTNAME, je vous parle depuis $PWD via un SHELL de type $SHELL"

je suis connecté en tant que aecn et j'habite à /home/aecn dans debian-work, je vous parle depuis /home/aecn/Documents/Formation/Le shell scripting/script/variables via un SHELL de type /bin/bash

Portabilité du script

Vous utilisez les variables de l’environnement où (et avec qui) vous exécuté le script.

Les variables d’environnement peuvent être différentes d’un environnement à un autre !

Exemple: variables/variable_6.sh

6- Les variables avec le retour d’une commande

Il est également possible de chargé une variable avec le retour d’une commande.


#!/bin/bash
#

DATE=$(date +"Année: %Y, Mois: %m, Jour: %d")           # La vairable DATE prend pour valeur le retour de la commande

echo "La date est $DATE"                                # Affiche la valeur de $DATE le retour de la commande
echo

list=$(ls -l)                                           # La variable $list prend la valeur de ls avec son argument -l

echo -e "le contenu du repertoire $PWD est\n$list"      # Affiche le contenu de la variable $list qui équivaut à un ls -l
echo

alias=$(grep ^alias $HOME/.bashrc)                      # Le script est portable et peut afficher les alias de l'utilisateur qui lance le script
                                                        # grace au variable d'environnement

echo -e "Mes alias sont:\n$alias"                       # Affiche les alias de l'utilisateur

Exemple: variables/variable_7.sh

7- Les variable local et exportable

Les variables peuvent être local se qui signifie qu’elles ne peuvent pas être utilisé en dehors de l’environnement choissi

Les variavles peuvent être exportable pour pouvoir être utilisées ailleurs que là où elles ont été déclarées


#!/bin/bash
#

list () {                                                       # Déclaration d'une fonction liste qui attend un argument
local dir                                                       # Déclaration d'une variable local dir
export extention                                                # Déclaration d'une variable export extention

dir="$1"                                                        # Dir prend pour valeur le premier argument de la fonction

la_liste=$(ls "$dir")                                           # la variable prend la valeur d'un ls de dir qui est le premier arguement de la fonction

echo -e "La liste fichier du répertoire $PWD\n$la_liste"        # Affiche les fichier présent dans la liste

extention=$(echo "$la_liste" | cut -d '.' -f2)                  # Défini la variable extention à la liste de fichiers séparé par un "." avec le deuxieme champ
}

list "$PWD"                                                     # Appel de la fonction avec comme paramètre la variable $PWD (ENV)

echo
echo "le répertoire est: $dir"                                  # Affiche le contenu de la variable $dir qui est local à la foncion (existe uniquement dans la fonction)
echo
echo -e "les extentions sont:\n$extention"                      # Affiche le contenu de la variable extention qui est exporté en dehors de la fonction

Exemple: variables/variable_9.sh
