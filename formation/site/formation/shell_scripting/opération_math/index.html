Les opérations mathématiques

Cette page présente l’utilisation des opérations mathématiques en BASH

Les opérations mathématiques

Les opérations mathématiques sont très utile en bash mais possèdes une syntaxe particulière. Les traitements d’un nombre peu être considérés de deux manières:

  • Un nombre peu être un entier exemple: 23
  • Un nombre peu être une chaîne de caractère ASCII exemple: caractère 2 et caractère 3 pour 23

0- Syntaxe

Les vérifications et les test éffectués sur une varible contenant un nombre peuvent être interprétés de plusieurs manières et ne pas répondre les mêmes codes retours ou les mêmes résultats.

Les interprétations


#!/bin/bash
#

#Déclaration de variable

nb0=23
nb1="023"
nb2="25"

nb3=10
nb4=2

if [ "$nb2" -gt "$nb0" ]
then
        echo "$nb2 est plus grand que $nb0"
fi

if [ "$nb3" < "$nb4" ]
then
        echo "$nb3 est plus petit que $nb4"
fi

if [[ "$nb3" < "$nb4" ]]        # Vérifie de manière lexicographique (ordre ASCII)
then
        echo "$nb3 est plus petit que $nb4"
fi

list="456 10 345 2"     #Liste de nombre sous forme de chaîne de caractère
list2=(456 10 345 2)    #Liste de nombre

sorted_list=($(printf "%s\n" "${list[@]}" | LC_ALL=C sort))
sorted_list2=($(printf "%s\n" "${list2[@]}" | LC_ALL=C sort))

echo "${sorted_list[@]}"
echo "${sorted_list2[@]}"

if [ "$nb3" -gt "$nb4" ]
then
        echo "$nb3 est plus grand que $nb4"
fi

Les tests de la norme POSIX

Il est nécessaire de comprendre la différence entre les test [ ] et [[ ]]

Syntaxe Découpage de mots Opérateur logique Gestion de motifs/regex Gestion des erreurs Gestion des variables NULL
[ ] ❌ ✅ -a -o ❌ ❌ erreur ❌ erreur
[[ ]] ✅ ✅ && || ✅ Wildcards / regex ✅ retour false ✅ Pas besion de guillemet retourne false
On considère que la syntaxe [[ ]] est plus robuste, moderne et permissive. Dans certain cas il est nécessaire et obligatoire d’utiliser cette syntaxe sous peine d’avoir de mauvais résultat dans le script.

Piège et norme

Le BASH respecte les normes POSIX !

Lorsque vous utilisé = ou == le résultat est le même.

Par contre, dans un test, si vous utilisez:

  • [ ] Utilisez uniquement = simple. Norme POSIX
  • [[ ]] Utilisez == uniquement pour des recherches de pattern (ex: *.txt sans guillemet)
  • [ ] Evitez d’utilisé le == pour la portabilité du script. Ne respecte pas la norme POSIX

Les nombres à virgule

Bash ne gère pas nativement les nombres flottants. Les opérations arithmétiques ($((...)), let) ne fonctionnent qu’avec des entiers. Pour les nombres à virgule, il faut utiliser des outils externes comme bc, awk, ou printf.

Bash n’est pas fais pour tous les usages. Si vous rencontrez le besoin d’utiliser des nombres à virgule, vous avez peu être pas choissi le bon language. Tournez vous vers Python par exemple.

Néanmoins si il est vraiment necéssaire de manipulé des nombres flottants il est possible de le faire en bash.

Ne pas oublier que bash n’est pas un language de programmation, il est présent pour exécuté des commandes avant tous.

La syntaxe avec des entiers

Syntaxe

nb1=23
nb2="025"

resultat=$(( nb1 opération nb2 ))

cmd=($(commande nb1))   # La commande traitera le contenu de la variable comme des entiers 
                        # (erreur si autre que entier dans la variable)
  • Première () signifie opération bash sur des entiers
  • Deuxième () signifie commande (ici opération mathématique)

Cette syntaxe est une commande, let qui vaut (( )), au même titre que test pour [ ].

1- Les opérations mathématiques

Les opérations mathématiques sont très utilise en scripting pour effectuer des calcules simples.


#!/bin/bash
#

nb1=${1:?Entrez un nombre}
nb2=${2:?Entrez un second nombre}

pos_result=$(( nb1 + nb2 ))
neg_result=$(( nb1 - nb2 ))
div_result=$(( nb1 / nb2 ))
mul_result=$(( nb1 * nb2 ))
mod_result=$(( nb1 % nb2 ))

echo "Le résultat de $nb1 + $nb2 est:" $pos_result
echo "Le résultat de $nb1 - $nb2 est:" $neg_result
echo "Le résultat de $nb1 / $nb2 est:" $div_result
echo "Le résultat de $nb1 * $nb2 est:" $mul_result
echo "Le résultat de $nb1 % $nb2 est:" $mod_result

Exemple: opération_math/math_3.sh

Les additions et soustractions sont également utilile pour des incrémentations possitive ou négative dans des boucles.


#!/bin/bash
#

while [[ -z $nb1 || -z $nb2 ]]
do
        while :
        do
                read -p "Entrez un nombre: " nb1
                if [[ $nb1 -gt 0 ]]
                then
                        break
                fi
        done

        while :
        do
                read -p "Entrez un deuxième nombre plus grand que le premier: " nb2
                if [[ $nb2 -gt $nb1 ]]
                then
                        break
                fi
        done
done

echo "premier nombre: " $nb1
echo "deuxième nombre: " $nb2


while [[ $nb1 -lt $nb2 ]]
do
        echo "Pas encore, Le premier nombre vaut $nb1"
        sleep 1
        nb1=$(( nb1 + 1 ))
done

echo "$nb1 est égale à $nb2"

Comportement caché

chiffre=toto
[[ $chiffre -lt 5 ]]  # Problème ici avec les entrées non-numériques
echo $?
0                     #TRUE

Pourquoi la chaîne de caractère “toto” renvoie TRUE

Conversion silencieuse : Bash convertit automatiquement les chaînes non-numériques en 0 dans les comparaisons arithmétiques

Logique du code :

  • “toto” → évalué comme 0
  • 0 < 5 → la condition devient vraie
  • Donc le script exécute le bloc if
